Elementor widgets, consultation forms and landing installer for КБФасад.

== Description ==

* Custom Elementor widgets for every landing section
* Modal and inline consultation forms via WordPress REST + wp_mail()
* Tools → КБФасад Landing installer for a one-click editable page
* Importable template snapshot in templates/landing.json (generated on install)

== Installation ==

1. Activate Elementor
2. Activate theme "КБФасад"
3. Activate plugin "КБФасад Elementor"
4. Open Tools → КБФасад Landing and install the page
5. Configure phones, email, address, map, social links and form recipient under Settings → КБФасад
